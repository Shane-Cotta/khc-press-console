## Words used in this guide

| Word | Meaning |
|---|---|
| **the console** | KHC Press Console: the Raspberry Pi with its touch screen, running this software |
| **the press console** | Mark 7's control box on the press, with the sensor ports and the power switch |
| **the press** | the reloading press and its motor, driven through the press console |
| **the card** | the SD card in the Raspberry Pi that holds KHC Press Console |
| **the home screen** | the console's main screen, with PRESS, FIRMWARE and the other main buttons |
| **STOP** | the red STOP sign on the right of every screen |
| **RUN** | the green button that runs the press continuously |

Words in bold capitals are written as the screen shows them: **RUN**, **CALIBRATE**, **ACCEPT**.
