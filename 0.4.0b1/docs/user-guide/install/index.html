    Installing KHC Press Console¶

    KHC Press Console comes as one ready-to-write SD card image for the Raspberry Pi 4 and the Raspberry Pi 5. You write it to a microSD card once. The Pi then starts straight into KHC Press Console, full screen. There is nothing to install on top, no login and no keyboard.

    Warning

    KHC Press Console is unofficial BETA software for real machinery. Read Safety before you connect a press.

    What you need¶

    • A Raspberry Pi 4 or Raspberry Pi 5, with 2 GB of memory or more.
    • The power supply for your Pi: the official Raspberry Pi USB-C supply (Pi 4: 5.1 V 3 A; Pi 5: 5 V 5 A) or an equivalent. A weak supply causes random restarts and faults.
    • A 10.1-inch 1920x1200 HDMI touch screen whose touch panel connects over USB, with its own 5 V supply, and a micro-HDMI to HDMI cable.
    • A microSD card of 8 GB or more. A good-quality card from a known brand (A1 or A2 rated) lasts longer; 16 or 32 GB is a sensible size.
    • A USB-A to micro-USB data cable for the press console (see Getting started).
    • A computer with an SD card reader, to write the card.

    Download¶

    1. Open the Releases page.
    2. From the newest release, download:
    3. khc-press-console-X.Y.Z-rpi.img.xz: the SD card image (X.Y.Z is the version number);
    4. SHA256SUMS.txt: the checksums of every file of that release.

    Check the download¶

    Checking tells you the image arrived complete and unchanged. Check the file as downloaded, still ending in .img.xz.

    1. Put both files in the same folder.
    2. Open a terminal in that folder (Windows: PowerShell; macOS: Terminal; Linux: any terminal).
    3. Run the command for your computer, below.

    macOS:

    shasum -a 256 -c --ignore-missing SHA256SUMS.txt

    Linux (including Raspberry Pi OS):

    sha256sum -c --ignore-missing SHA256SUMS.txt

    On macOS and Linux the image's line must end in OK. FAILED means it does not match. If nothing is printed, the image is not in that folder, or it has another name.

    Windows (PowerShell):

    Get-FileHash .\khc-press-console-X.Y.Z-rpi.img.xz -Algorithm SHA256

    Windows does not compare for you. Open SHA256SUMS.txt in Notepad and compare the long number on the image's line with the one PowerShell printed. Every character must be the same; upper or lower case does not matter. (In Command Prompt instead: certutil -hashfile khc-press-console-X.Y.Z-rpi.img.xz SHA256.)

    Each release also has khc-press-console-X.Y.Z-rpi.img.xz.sha256, the image's checksum on its own, in the same format. You can check against it instead of SHA256SUMS.txt.

    Caution

    If the checksum does not match, do not use the file. Download the image and SHA256SUMS.txt again, from the same release, and check again (a download that stopped early is the usual cause). Make sure you downloaded from the official releases page. If it still fails, report it as an issue with the file name and the output of the check.

    Write the card with Raspberry Pi Imager¶

    Install Raspberry Pi Imager (Windows, macOS or Linux) and put the microSD card in your computer's card reader.

    1. Choose Device: pick Raspberry Pi 4 or Raspberry Pi 5, whichever you have.
    2. Choose OS: scroll to the very bottom of the list and pick Use custom. Select the downloaded khc-press-console-X.Y.Z-rpi.img.xz. There is no need to unzip it first.
    3. Choose Storage: pick the microSD card. Look at the size to be sure it is the card: everything on it is erased.
    4. Next. If Imager asks whether to apply OS customisation settings, answer No (see below). Current versions of Imager do not offer customisation for a custom image, so you may not be asked.
    5. Confirm that the card will be erased. Imager writes the card and then verifies it (reads it back). This takes a few minutes.
    6. When Imager says the card can be removed, take it out.

    OS customisation: answer No¶

    The card configures itself: its name on the network, its firewall, the kiosk that runs the console, and Wi-Fi (which you set up later on the console's own screen). It needs no user account, no SSH (the card has no SSH server) and no Wi-Fi settings from Imager. Imager's customisation is not supported for it.

    • Current Imager versions (2.x) skip the customisation step for a custom image. Nothing to do.
    • Older Imager versions (1.8, 1.9) ask "Would you like to apply OS customisation settings?". If you answer Yes, they add a first-start script made for older Raspberry Pi OS releases. This card is built on a newer release, so those settings would not be applied reliably, and the first start could behave unexpectedly (for example an extra restart, a changed network name, or Wi-Fi switched on without a country set on the console). Answer No.

    If you answered Yes by mistake, write the card again and answer No.

    Other ways to write the card¶

    • balenaEtcher (etcher.balena.io) also reads .img.xz directly: Flash from file, pick the image, Select target (the card), Flash. It verifies the card afterwards.
    • From a terminal on Linux (on macOS, use Imager or balenaEtcher):

    sh xz -dc khc-press-console-X.Y.Z-rpi.img.xz | sudo dd of=/dev/<your card> bs=4M conv=fsync status=progress

    Find the card's device name first with lsblk (the whole card, for example /dev/sdb or /dev/mmcblk0, not a partition), and unmount its partitions.

    Caution

    dd overwrites whatever device you give it, without asking. A wrong device name can erase your computer's disk.

    First start¶

    1. Wire the Pi, the screen and the press console as in Getting started.
    2. Switch the screen on, then plug in the Pi's power. The Pi has no power switch: it starts when power is applied.
    3. The screen shows the boot animation while the system starts.
    4. The very first start takes about a minute longer than later ones: the card grows to use the whole microSD card and finishes its one-time setup. Do not unplug the Pi during it.
    5. The home screen appears, and the terms of use open by themselves, page by page. Read them and tap I AGREE on the last page (the same text is in Terms of use).
    6. The welcome screens follow: Wi-Fi (or SKIP), then a license or the 10-day trial. See The trial and your license.
    7. Back on the home screen, the status line reads Press not connected. Nothing is sent to the press until you tap CONNECT or PRESS and ACCEPT.

    Next: Getting started. If the screen stays black, see Troubleshooting.

    Updating later¶

    A console updates itself from SOFTWARE UPDATE, over Wi-Fi or Ethernet, or from a USB stick: see Software updates. You do not need to write a new card for an update.

    Writing a new card with a newer image also works, and some releases need it (their release notes say so). But a new card starts from scratch.

    Important

    Writing a new card erases everything the console kept on the old one: your settings, the saved Wi-Fi networks, the settings files saved on the console, and the backups of your press's firmware. A licensed Raspberry Pi gets its license back by itself once it is online (A new SD card).
